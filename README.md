🛍️ Superstore Sales Analysis – Exploratory Data Analysis (EDA):

About the Project:

This project focuses on analyzing Superstore sales data using Python. The purpose is to understand sales performance and identify useful business insights from the dataset.

Project Objectives:

Understand the sales dataset.
Clean the data and handle missing values.
Remove duplicate records.
Analyze sales by category and region.
Identify monthly sales trends.
Present findings using chart

🛠️ Tools & Technologies

- 🐍 Python
- 🐼 Pandas
- 📈 Matplotlib
- 📓 Jupyter Notebook

🔍 Project Workflow

1. Dataset Loading and Exploration
2. Data Cleaning and Preprocessing
3. Handling Missing Values
4. Removing Duplicate Records
5. Exploratory Data Analysis
6. Data Visualization
7. Business Insights and Findings

📊 Visualizations

- Sales by Product Category
- Sales by Region
- Sales by Sub-Category
- Monthly Sales Trend

💡 Key Business Insights

- Technology generated the highest sales among the three product categories.
- Office Supplies generated the lowest sales among the three categories.
- Sales performance varies across different regions.
- Sales contributions differ among product sub-categories.
- Monthly sales trends help identify changes in business performance.

📁 Project Files
